Feature schema

One schema, four seats, thirty-eight signals.

Every scene is described by this feature set — the questions Track B must answer, and the ground truth Track A must preserve. Values are null when the corresponding seat, passenger, or object isn't present. Track A and B notebooks each evaluate only the subset relevant to that track.

Values are null when the seat, passenger, or object is absent.
